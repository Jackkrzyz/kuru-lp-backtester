## LP setup

- Shape: Spot
- Minimum price: 0.0263 USDC per MON
- Maximum price: 0.02795 USDC per MON
- Fee and flip spread: 30 bps
- MON deposit: 2,000
- USDC deposit: 60
- Initial grid: 11 bids and 10 asks
- Required ratio: 33.3333333333 MON per USDC
- Initial inclusion delay: one block
- Transaction participation cap: 10 percent
- Maker fee: 0
- Fixed action cost: 0

All 21 initial orders join the historical queue tail. The engine creates a paired order on the first partial fill. Later partial fills update the same paired order. A paired order keeps its queue position when its size increases. A new paired order joins the tail. The engine does not do periodic cancellation or replacement.

The minimum-size audit matches the official OrderBook contract. Initial user-provided flip orders must meet `minSize`. The contract's internal flip update can create one paired order below `minSize` after a small partial fill. Later fills add to the same paired order. This is a contract-valid internal order, not a second user placement. Tests confirm that the simulator keeps the assets, keeps one paired order, and rejects a below-minimum initial order.
